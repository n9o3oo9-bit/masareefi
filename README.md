# مصاريفي

تطبيق لمتابعة وتقسيم المصاريف الشخصية على دفعات الدخل، مع متابعة أسبوعية للصرف ومزامنة بين الأجهزة.

ملف واحد `index.html` — بلا إطارات عمل ولا خطوات بناء للمتصفح. خط ثمانية مدمج داخله، فيعمل بلا إنترنت.

---

## التشغيل الآن (بدون أي إعداد)

اضغط `index.html` مرتين. البيانات تُحفظ في متصفحك، والمزامنة معطّلة.

## الأقسام

| القسم | الوظيفة |
|---|---|
| **نظرة عامة** | الدخل، الملتزم به، المتبقي الحر، تقدّم الدفع، وملخّص الأسبوع |
| **الأسبوعي** | حلقة الميزانية الأسبوعية، صرف كل يوم، أسابيع الشهر، وسجل الصرف |
| **الرواتب** | الدفعات وما على كل واحدة، وتعديل الدخل وتواريخه |
| **البنود** | الجدول الكامل — إضافة وتعديل وحذف وأرشفة |
| **طارئة** | مصاريف تخصّ هذا الشهر فقط |
| **المنتهية** | التزامات انتهت — خارج حساب الشهر |

**الزر الأخضر (+)** أسفل الشاشة يسجّل مصروفًا في أي وقت من أي قسم.

---

## المتابعة الأسبوعية

أي بند يمكن تفعيل ميزانية أسبوعية له: **البنود ← تعديل ← «تتبّع الصرف أسبوعيًا»**. المصروف الشخصي مفعّل مسبقًا بـ ١٥٠ ريال.

الأسبوع يبدأ **السبت** وينتهي الجمعة. التطبيق يحسب لك تلقائيًا:

- المتبقي من ميزانية الأسبوع (الحلقة الكبيرة — تتحول برتقالية عند ٨٠٪ وحمراء عند التجاوز)
- **كم تقدر تصرف يوميًا** حتى نهاية الأسبوع دون تجاوز
- صرف كل يوم على حدة، وأسابيع الشهر كلها

سجّل المصروف من الزر (+) أو بالضغط على أي يوم في شريط الأيام.

---

## تعديل الدخل وتواريخه

**الإعدادات (⚙) ← دفعات الدخل**. لكل دفعة: الاسم، يوم الوصول (١–٣١)، والمبلغ. تقدر تضيف دفعات جديدة أو تحذف دفعة (تُصفّر توزيعاتها في كل البنود بعد تأكيد).

## المزامنة بين الأجهزة

تحتاج خطوتين تُنفَّذان مرة واحدة: **Firebase** لتخزين البيانات، و**GitHub Pages** لاستضافة الرابط.

### ١. إنشاء مشروع Firebase

1. افتح [console.firebase.google.com](https://console.firebase.google.com) ← **Add project** ← سمّه `masareefi` ← تقدر تعطّل Google Analytics.
2. **Build ← Firestore Database ← Create database** ← اختر **Production mode** ← اختر موقعًا قريبًا (`eur3` أو `nam5`).
3. **Firestore ← Rules** ← امسح الموجود والصق محتوى ملف [`firebase.rules`](firebase.rules) ← **Publish**.
   هذه الخطوة ضرورية: بدونها إمّا تُرفض القراءة أو تُفتح بياناتك للجميع.
4. **Build ← Authentication ← Get started ← Google ← Enable** ← اختر إيميل الدعم ← **Save**.
5. **Project settings (⚙) ← General** ← انزل لـ **Your apps** ← أيقونة الويب `</>` ← سمّه `masareefi` ← **Register app**.
6. انسخ كائن `firebaseConfig` الظاهر — يشبه هذا:

   ```json
   {
     "apiKey": "AIza…",
     "authDomain": "masareefi-xxxx.firebaseapp.com",
     "projectId": "masareefi-xxxx",
     "storageBucket": "masareefi-xxxx.appspot.com",
     "messagingSenderId": "1234567890",
     "appId": "1:1234567890:web:abcdef"
   }
   ```

7. احفظه في ملف `firebase.config.json` بجانب `build.py`، ثم:

   ```bash
   python3 build.py
   ```

   > **بديل بدون إعادة بناء:** افتح التطبيق ← الإعدادات ← «إعداد Firebase» ← الصق الكائن ← حفظ. لكنك ستكرر ذلك على كل جهاز، لذا الأفضل بناؤه داخل الملف.

**عن المفاتيح:** `apiKey` في تطبيقات الويب معرّف عام وليس سرًّا — يظهر في كل تطبيق Firebase. الحماية تأتي من قواعد Firestore أعلاه ومن تسجيل الدخول، لا من إخفائه.

### ٢. النشر على GitHub Pages

أنشئ مستودعًا عامًا باسم `masareefi` من [github.com/new](https://github.com/new) (بدون README)، ثم:

```bash
git remote add origin https://github.com/<اسم-حسابك>/masareefi.git
git branch -M main
git push -u origin main
```

ثم في المستودع: **Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` / `(root)` ← Save**.

بعد دقيقة يصير الرابط جاهزًا:

```
https://<اسم-حسابك>.github.io/masareefi/
```

### ٣. ربط النطاق بـ Firebase

آخر خطوة وإلا سيُرفض تسجيل الدخول:

**Firebase ← Authentication ← Settings ← Authorized domains ← Add domain** ← أضف `<اسم-حسابك>.github.io`.

### ٤. الاستخدام

افتح الرابط على الجوال والحاسب ← اضغط **«سجّل الدخول»** في الأعلى ← حساب Google. أي تعديل يصل لبقية أجهزتك خلال ثوانٍ.

على الآيفون: سفاري ← مشاركة ← **إضافة إلى الشاشة الرئيسية** ← يصير تطبيقًا مستقلًا يعمل بلا إنترنت.

## بعد أي تعديل

عدّل `app.template.html` ثم:

```bash
python3 build.py && git add -A && git commit -m "وصف التعديل" && git push
```

يظهر التحديث على الرابط خلال دقيقة تقريبًا.

> افتح **`index.html`** دائمًا، لا `app.template.html` — القالب بلا خط، وسيحذّرك إن فتحته بالخطأ.

## البيانات والخصوصية

- **بدون مزامنة:** كل شيء في متصفحك فقط. مسح بيانات المتصفح يمسحها.
- **مع المزامنة:** نسخة في Firestore تحت حسابك، لا يصل إليها غيرك.
- **نسخة احتياطية:** الإعدادات ← تصدير ملف. ملفات `مصاريفي-*.json` مستثناة من Git.
- التعديل من جهازين في نفس اللحظة: تفوز آخر كتابة. عمليًا نادر لأن التحديث يصل خلال ثوانٍ.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق — **هذا ما تفتحه** |
| `app.template.html` | المصدر القابل للتعديل |
| `build.py` | يبني `index.html` (خط + إعداد Firebase) |
| `firebase.rules` | قواعد أمان Firestore |
| `firebase.config.json` | إعدادك (تنشئه أنت) |
| `sw.js` · `manifest.webmanifest` · `icon.svg` | العمل بلا إنترنت والتثبيت كتطبيق |
| `fonts/` | خط ثمانية — مصدر البناء |
